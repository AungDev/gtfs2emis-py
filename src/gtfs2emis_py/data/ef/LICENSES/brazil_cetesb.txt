CETESB — Companhia Ambiental do Estado de São Paulo
===================================================

Source: "Emissões veiculares no estado de São Paulo" (CETESB, 2019)
https://cetesb.sp.gov.br/veicular/

This table is NOT redistributed in the wheel. The Python loader fetches it only
on request (`load_ef_table("brazil_cetesb", fetch=True)`), downloading the original
pinned `.rda` from the URL recorded in `manifest.json`.

was located. It is treated as unlicensed until the source owner provides written
terms. Attribution alone is not permission to redistribute it.

commit 0dbca7d779857145888ab695f36dc9e71ff57d98. The R package's MIT licence
